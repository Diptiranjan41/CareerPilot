# CareerPilot 🚀

AI-powered career assistant platform designed to help users improve their career journey with personalized recommendations, interview preparation, skill analysis, and job guidance.

CareerPilot provides an all-in-one solution for students and job seekers by combining AI-based career assistance with modern full-stack technologies.

## ✨ Features

### 📄 AI Resume Builder

* Create professional resumes easily
* Generate structured resume content
* Improve resume quality for better job opportunities

### 🎯 Career Guide

* Personalized career guidance
* Skill improvement suggestions
* Career path recommendations based on user goals

### 💼 Job Recommendation System

* Provides relevant job recommendations
* Helps users identify suitable career opportunities
* Matches skills with job requirements

### 🎤 Interview Preparation

* Practice technical and HR interview questions
* Improve interview confidence
* Prepare for real-world placement interviews

### 📝 Mock Test Platform

* Skill-based mock tests
* Practice coding and aptitude questions
* Track performance and improvement

### 🔐 Authentication & Security

* Google OAuth Authentication
* JWT-based user authentication
* Secure login and user data protection

### 📊 User Dashboard

* Manage profile and career activities
* Track learning progress
* Access personalized recommendations
